# разом — спільний простір для двох

Мінімалістичний сайт для спільного малювання та фото. Фронтенд публікується на GitHub Pages, дані зберігає Firebase.

## Що потрібно

- Обліковий запис GitHub
- Обліковий запис Google для Firebase
- Браузер із підтримкою JavaScript modules
- Інтернет для роботи Firebase

## 1. Створи Firebase-проєкт

1. Відкрий https://console.firebase.google.com/ і натисни **Create a project**.
2. У проєкті натисни значок Web `</>` та зареєструй вебзастосунок.
3. Скопіюй конфігурацію Firebase SDK у файл `firebase-config.js`, замінивши всі значення `PASTE_...`.
4. У **Build → Authentication → Sign-in method** увімкни **Anonymous**.
5. У **Build → Realtime Database** створи базу. Обери регіон і скопіюй URL бази в `databaseURL` у конфігурації.
6. На вкладці **Rules** Realtime Database встав вміст `database.rules.json` і натисни **Publish**.
7. У **Build → Storage** створи сховище. Якщо Firebase просить налаштувати тарифний план для Storage, перевір актуальні умови й можливі витрати перед продовженням.
8. У Storage → Rules встав вміст `storage.rules` і натисни **Publish**.
9. Перевір `storageBucket` у `firebase-config.js`: скопіюй точне значення з налаштувань свого Firebase-проєкту. Формат bucket може відрізнятися залежно від проєкту.

## 2. Важливо про доступ і безпеку

Цей навчальний стартовий варіант використовує анонімну автентифікацію та випадковий довгий ID кімнати. Однак наведені прості правила бази дозволяють будь-якому автентифікованому користувачу Firebase читати й змінювати дані кімнат, якщо він знає їхній ID. Посилання працює як секретний ключ, але це **не повноцінна модель приватності**.

Не зберігай чутливі фотографії в цій версії. Для справжньої приватності потрібна перевірка членства в конкретній кімнаті через правила Firebase (і відповідна схема запрошень), а також обмеження видалення файлів. Не публікуй серверні ключі або service account credentials. Firebase Web API key сам по собі не є паролем — доступ контролюється правилами.

## 3. Опублікуй сайт на GitHub Pages

1. На GitHub створи новий **Public** repository, наприклад `razom-space`.
2. Завантаж у корінь репозиторію всі файли: `index.html`, `style.css`, `app.js`, `firebase-config.js`, `database.rules.json`, `storage.rules`, `README.md`.
3. Відкрий **Settings → Pages**.
4. У **Build and deployment** вибери **Deploy from a branch**.
5. Обери гілку `main` і папку `/ (root)`, натисни **Save**.
6. Зачекай, поки GitHub опублікує сайт. Посилання буде приблизно таким: `https://ТВІЙ-USERNAME.github.io/razom-space/`.

## 4. Як користуватися

1. Відкрий сайт і натисни **Створити наш простір**.
2. Сайт створить випадковий ID кімнати та спробує скопіювати запрошення.
3. Надішли повне посилання дівчині.
4. Вона відкриває його на своєму телефоні. Малюнки та фотографії синхронізуються через Firebase.
5. Обидва можуть завантажувати фото в розділі **Наші фото**.

## 5. Як перевірити

- Відкрий посилання у двох різних браузерах або на телефоні й комп'ютері.
- Намалюй кілька штрихів і перевір, чи з'являються вони на другому пристрої.
- Завантаж тестове фото.
- Перевір, що кнопки «Очистити» та «Назад» працюють як очікується.
- Якщо щось не працює, відкрий Developer Tools → Console і перевір помилки Firebase.

## Обмеження цієї першої версії

- Для доступу потрібне інтернет-з'єднання та активна конфігурація Firebase.
- Firebase може мати ліміти або вимагати тарифний план залежно від поточних умов.
- Синхронізація малювання та галереї вимагає перевірки після налаштування реального проєкту.
- Це початкова версія, а не аудитований приватний сервіс.
